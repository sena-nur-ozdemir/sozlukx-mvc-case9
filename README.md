# 📖 SözlükX | MVC Sözlük Uygulaması — Case #9

**SözlükX**, kullanıcıların kategorilere bağlı başlıklar oluşturabildiği, entry paylaşabildiği ve mesajlaşabildiği bir sözlük uygulamasıdır.

Proje, **M&Y Yazılım Eğitim Akademi .NET Full Stack Bootcamp** çalışmaları kapsamında, **Murat Yücedağ'ın YouTube'daki 100 derslik MVC Proje Kampı** serisi temel alınarak **Case #9** olarak geliştirilmiştir. Eğitimdeki katmanlı mimari ve veri yönetimi yaklaşımı, SözlükX'e özel arayüzle uygulanmıştır.

## 🧩 N Katmanlı Mimari

- **EntityLayer:** Varlık sınıfları ve tablo ilişkileri
- **DataAccessLayer:** Entity Framework 6, DbContext, Generic Repository ve veri erişim işlemleri
- **BusinessLayer:** Manager sınıfları, iş kuralları ve doğrulamalar
- **Case9MvcSozluk (Presentation):** ASP.NET MVC Controller'ları, Razor View'lar ve kullanıcı arayüzü

**Öne çıkan konular:** Code First, Migrations, LINQ, Generic Repository Pattern, CRUD işlemleri, ilişkisel veritabanı, Forms Authentication ve yönetici/yazar yetkilendirmesi.

## 🛠️ Teknolojiler

**C# · ASP.NET MVC 5 · .NET Framework 4.8 · Entity Framework 6 · SQL Server · LINQ · Razor Views · HTML · CSS · JavaScript · Bootstrap**

## 🚀 Uygulama Özellikleri

- Kategori, başlık ve entry listeleme; arama ve sıralama
- Yazar kayıt/giriş, profil ve kendi içeriklerini yönetme
- Gelen/gönderilen mesajlar ve taslaklar
- Kategori, yazar, başlık ve entry yönetimi için admin paneli
- Hakkımızda, iletişim, galeri ve veritabanına dayalı istatistik ekranları

## 🎨 Yapay Zekâ Destekli Tasarım Süreci

SözlükX'in ön yüzü hazırlanan HTML temasından **Razor View** yapısına uyarlanmıştır. **Yönetim paneli ise hazır bir admin şablonu kullanılmadan, yapay zekâ desteğiyle tasarlanmış** ve HTML, CSS, JavaScript ile MVC projesine entegre edilmiştir.

> Yapay zekâ, **tasarım ve geliştirme sürecinde yardımcı araç** olarak kullanılmıştır; uygulamanın içinde çalışan bir AI modeli veya AI servisi bulunmamaktadır.
